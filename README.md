# إنجاز — تطبيق إدارة المهام والمشاريع

تطبيق ويب عربي متجاوب لتنظيم المهام اليومية ومتابعة المشاريع، مبني باستخدام HTML وCSS وJavaScript فقط.

## المميزات
- لوحة إحصائيات لإجمالي المهام، مهام اليوم، المكتملة والمتأخرة.
- إضافة المهام وتعديلها وحذفها.
- تحديد الأولوية وتاريخ الاستحقاق وربط المهمة بمشروع.
- تصنيف المهام حسب الحالة، والبحث، والترتيب.
- إنشاء مشاريع متعددة ومتابعة نسبة إنجاز كل مشروع.
- حفظ البيانات تلقائيًا في `localStorage`.
- مظهر فاتح وداكن.
- واجهة عربية RTL متجاوبة مع الهواتف والأجهزة اللوحية.
- بيانات تجريبية تظهر عند أول تشغيل.

## تشغيل المشروع محليًا
1. فك ضغط ملف ZIP.
2. افتح `index.html` في المتصفح.
3. لا يحتاج المشروع إلى تثبيت مكتبات أو خادم خلفي. يتطلب خط Cairo اتصالًا بالإنترنت إذا لم يكن مخزنًا في المتصفح.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub، مثل `Injaz-Task-Manager`.
2. ارفع الملفات التالية إلى جذر المستودع: `index.html`, `style.css`, `script.js`, `README.md`.
3. افتح **Settings → Pages**.
4. في **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
6. انتظر اكتمال النشر، ثم افتح رابط الموقع الذي يظهر في صفحة Pages.

## الملفات
- `index.html` — هيكل التطبيق والنوافذ المنبثقة.
- `style.css` — التصميم المتجاوب والألوان والمظهر الداكن.
- `script.js` — إدارة المهام والمشاريع والتخزين المحلي والتفاعلات.

## ملاحظات
- هذا نموذج Front-end للتجربة وعرض الأعمال؛ لا يتضمن تسجيل دخول حقيقيًا أو مزامنة بين الأجهزة أو قاعدة بيانات سحابية.
- البيانات محفوظة في المتصفح الحالي فقط. مسح بيانات المتصفح قد يؤدي إلى حذفها.
- المشروع قابل للتطوير لاحقًا بإضافة واجهة خلفية وقاعدة بيانات ونظام حسابات.
